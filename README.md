# Customer Segmentation Using RFM Analysis

## Project Overview

This project uses Microsoft Power BI to analyze customer purchasing behavior using Recency, Frequency, and Monetary (RFM) analysis.

The dashboard helps businesses understand customer behavior, identify valuable customer segments, and develop targeted marketing strategies.

## Objectives

- Clean and prepare transactional customer data.
- Calculate Recency, Frequency, and Monetary (RFM) metrics.
- Assign RFM scores to customers.
- Segment customers based on purchasing behavior.
- Analyze customer behavior patterns.
- Recommend targeted marketing strategies.
- Visualize customer insights using interactive Power BI dashboards.

## Tools and Technologies

- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization
- RFM Analysis

## RFM Methodology

### 1. Recency (R)

Measures how recently a customer made a purchase.

**Importance:** Recent customers may be more likely to respond to promotions and special offers.

### 2. Frequency (F)

Measures how frequently a customer makes purchases.

**Importance:** Frequent customers may be more loyal and are potential targets for retention and upselling campaigns.

### 3. Monetary Value (M)

Measures how much money a customer spends.

**Importance:** Identifies high-value customers who may benefit from personalized offers and loyalty rewards.
