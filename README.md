# Customer Segmentation Using RFM Analysis

## Project Overview
This project uses Microsoft Power BI to analyze customer purchasing behavior using Recency, Frequency, and Monetary (RFM) analysis.

The dashboard helps identify customer segments and provides insights to support targeted marketing strategies.

## Objectives
- Analyze customer purchasing behavior.
- Calculate Recency, Frequency, and Monetary metrics.
- Assign RFM scores to customers.
- Segment customers based on purchasing patterns.
- Identify loyal, new, and at-risk customers.
- Recommend targeted marketing strategies.

## Tools Used
- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

## Dashboard Pages
1. Customer Demographics
2. Customer Segmentation
3. Customer Details
4. Segment Description

## Key Features
- Customer demographic analysis
- RFM scoring and segmentation
- Sales analysis by customer group
- Marketing recommendations
